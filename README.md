HGV Transport Compliance Management System

Project Overview

The HGV Transport Compliance Management System is a Python-based application developed as part of the PFD200 Professional Development module.
The project aims to support the organisation and management of transport compliance information for Heavy Goods Vehicle (HGV) operations.

Project Objectives

- Manage driver information.
- Record and monitor driver working hours.
- Record vehicle safety checks.
- Track compliance requirements and reminders.
- Record transport-related incidents.
- Store and retrieve information using CSV files.

Technologies Used

- Python
- CSV file storage
- Visual Studio Code
- GitHub for version control
- Jira for Agile project management

Current Development Progress

The following functionality has been implemented:

- Initial Python project structure
- Command-line menu
- Basic driver management
- CSV file storage

Additional compliance features are planned for subsequent development stages.

Project Management

The project is managed using Jira, with tasks organised into sprints. GitHub is used to track code changes and link development commits to Jira issues.

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run `python main.py`.
